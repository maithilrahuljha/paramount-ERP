SECTION 15: DEPLOY APPLICATION
--------------------------------------------------------------------------------

Now we deploy your application to the cloud.

STEP 15.1: Clone your repository
   • In Cloud Shell, type:
   
   git clone https://github.com/YOUR_USERNAME/pmn-erp-platform.git
   
   (Replace YOUR_USERNAME with your actual GitHub username)
   
   • Press Enter
   • If asked for username: Type your GitHub username
   • If asked for password: You need a Personal Access Token
   
   HOW TO CREATE PERSONAL ACCESS TOKEN:
   • Open new tab: github.com
   • Click your avatar (top-right)
   • Click "Settings"
   • Scroll down, click "Developer settings"
   • Click "Personal access tokens" > "Tokens (classic)"
   • Click "Generate new token" > "Generate new token (classic)"
   • Note: type "deployment"
   • Expiration: 90 days
   • Check "repo" checkbox
   • Click "Generate token"
   • COPY THE TOKEN IMMEDIATELY (you won't see it again)
   • Use this token as the password in Cloud Shell

STEP 15.2: Enter project folder
   • Type:
   
   cd pmn-erp-platform
   
   • Press Enter

STEP 15.3: Create environment file
   • Type this ENTIRE command (copy-paste is best):
   
   cat > .env << EOF
   DATABASE_URL=YOUR_DATABASE_URL_HERE
   JWT_SECRET=YOUR_JWT_SECRET_HERE
   NODE_ENV=production
   EOF
   
   • Replace YOUR_DATABASE_URL_HERE with your actual DATABASE_URL
   • Replace YOUR_JWT_SECRET_HERE with your actual JWT_SECRET
   • Press Enter

STEP 15.4: Build the application
   • Type:
   
   gcloud builds submit --tag gcr.io/$(gcloud config get-value project)/pmn-erp
   
   • Press Enter
   • ⏰ WAIT: This takes 5-10 minutes
   • You will see lots of text scrolling
   • Wait until you see "SUCCESS"

STEP 15.5: Deploy to Cloud Run
   • Type this entire command:
   
   gcloud run deploy pmn-erp --image gcr.io/$(gcloud config get-value project)/pmn-erp --platform managed --region asia-south1 --allow-unauthenticated --set-env-vars "NODE_ENV=production" --memory 512Mi
   
   • Press Enter
   • When asked about environment variables, press Enter for default
   • When asked "Allow unauthenticated invocations?", type: y
   • Press Enter
   • ⏰ WAIT: 2-3 minutes

STEP 15.6: Note your URL
   • After deployment, you will see:
   
   Service URL: https://pmn-erp-xxxxx-xx.a.run.app
   
   WRITE YOUR SERVICE URL HERE:
   _____________________________________________

CHECKPOINT: Application is deployed!

   • Usually works within 30 minutes

SECTION 29: COMMON PROBLEMS
--------------------------------------------------------------------------------

PROBLEM: Cannot access the login page
---------------------------------------
SOLUTION:
□ Check if the URL is correct (https://erp.pmn.edu.in)
□ Try clearing browser cache:
  • Chrome: Press Ctrl+Shift+Delete > Clear data
□ Try a different browser
□ Check internet connection
□ Wait 5 minutes and try again


PROBLEM: Login fails with correct password
------------------------------------------
SOLUTION:
□ Check CAPS LOCK is OFF
□ Make sure email is complete (@pmn.edu.in)
□ Try copy-pasting password (avoid typos)
□ Ask admin to reset your password
□ Clear browser cache and cookies


PROBLEM: 2FA code not working
-----------------------------
SOLUTION:
□ Check your phone's time is set to AUTOMATIC
  (Settings > Date/Time > Automatic)
□ Make sure you're using the code for "PMN ERP Platform"
□ Wait for next code (they change every 30 seconds)
□ Try typing faster before code expires
□ Use a backup code instead
□ Contact admin if all backup codes used


PROBLEM: Page shows error or won't load
---------------------------------------
SOLUTION:
□ Refresh the page (F5 or Ctrl+R)
□ Clear browser cache
□ Try different browser
□ Check internet connection
□ Wait 10 minutes (server might be restarting)
□ Contact admin with screenshot of error


PROBLEM: Data not saving
------------------------
SOLUTION:
□ Check all required fields are filled (marked with *)
□ Check red error messages on the form
□ Try clicking Save again
□ Refresh page and try again
□ Check internet connection


PROBLEM: Cannot see certain leads
---------------------------------
SOLUTION:
□ If you're a Counsellor, you only see assigned leads
□ Ask Manager to assign leads to you
□ Use search/filter to find specific lead
□ Check if filters are applied (clear them)


PROBLEM: Forgot password
------------------------
SOLUTION:
□ Contact your administrator
□ They can reset your password from Settings > Users
